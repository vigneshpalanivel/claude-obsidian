# Infographic Image Prompts — Workout Plan

Prompts for generating the workout plan as a **poster image** (not HTML). Paste into GPT Image / ChatGPT, Nano Banana / Gemini, Ideogram, or Midjourney.

> 🔴 **Read this first — it determines which prompt you should use.** Image models still garble dense text. A poster carrying 30 exercises with sets, reps and cues will come back with misspelled and invented words no matter how good the prompt is. **The fix is fewer words per image, not a better prompt.** So: use Option B (three posters) if you want it accurate and usable, Option A only if you want one decorative overview. **Ideogram and GPT Image handle poster text far better than Midjourney** — use one of those.

---

## OPTION A — Single overview poster (decorative, minimal text)

Deliberately stripped down. Exercise names only, no cues, no sets/reps — that is what makes it survive generation.

```
A clean modern fitness infographic poster, vertical 4:5, dark charcoal
background (#15171c) with teal (#35c6b4) and amber (#f0a94c) accents.

Title at top: "STRENGTH PLAN"

Below the title, a horizontal row of 7 small rounded boxes labeled
MON TUE WED THU FRI SAT SUN.

Below that, two columns of rounded cards side by side. Left column
header "WORKOUT A" in teal, right column header "WORKOUT B" in amber.

Each card holds one simple flat-vector line-art stick figure showing an
exercise, with a short label underneath.

Left column figures: push-up, inverted row under a low bar with an
underhand grip, floor chest fly with dumbbells, bicep curl, step-up onto
a box, lying hamstring slide, wall sit, single-leg calf raise, prone
Y-raise with arms lifted off the floor.

Right column figures: seated overhead dumbbell press, lowering slowly
from the top of a pull-up bar, inverted row with a wide overhand grip,
rear delt fly, tricep kickback, glute bridge, side-lying clamshell,
prone leg lift, wrist curl.

Bottom band in red (#e5645e) titled "EVERY DAY" with three figures:
bird dog, dead bug, side plank.

Style: minimalist flat vector, thin uniform line weight, no shading,
no facial features, no gym background, generous whitespace, clinical
health-app aesthetic. Short labels only — no paragraphs, no numbers,
no watermark, no logo.
```

## OPTION B — Three posters *(recommended)*

Splitting the content roughly triples text accuracy, because each image carries a third as many words. Generate all three in one session so the style matches.

## If the text still comes out wrong

1. **Regenerate 3–4 times and pick the best** — text accuracy varies run to run more than any prompt change will fix.
2. **Drop the numbers entirely** — remove all sets/reps, keep only exercise names. Names alone survive almost every generation.
3. **Fall back to the plan itself** — [[exercise-plan]] has the full sets, reps and cues in text. Use the poster as a wall reference and the plan as the source of truth.
